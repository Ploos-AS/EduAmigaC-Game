## M1 — First playable

Deliver the first small playable program in all three tracks.

Required concepts:

- program lifecycle;
- game loop;
- frame timing;
- keyboard/joystick input;
- moving object;
- clean exit.

The result must be small enough that students can understand every important line.

## M2 — First complete mini-game

Create a Pong/Breakout-class game in all three tracks.

Include:

- rendering;
- input;
- collision;
- score;
- states;
- basic sound;
- restart and exit;
- comparison chapter.

## M3 — Core 2D systems

Add:

- sprites/BOBs;
- animation;
- tile maps;
- scrolling;
- cameras;
- actor management;
- collision systems;
- asset pipeline.

## M4 — Audio and presentation

Add Paula/audio fundamentals, music, sound effects, HUDs, menus, palettes and visual effects.

## M5 — Complete game

Build a substantial course game in all three tracks.

## M6 — Advanced optimisation

Add profiling and optimisation for classic 68k targets, including CPU/blitter scheduling and memory constraints.

## M7 — Capstone and publication readiness

Complete capstone material, exercises, solutions, instructor/reviewer validation, publishing outputs and release qualification.
